# 輕鬆寫 · AI 小說創作工坊

一個可以直接部署在 GitHub Pages 上的純前端 AI 小說創作網站。可以用專案方式管理每一部作品，設定寫作風格、參考作品、小說性質、人稱視角、人物規模、章節架構、世界觀、時間線、特殊名詞與故事限制，並讓 AI 依這些設定逐章逐節生成小說內容。

- 純靜態網頁（HTML + CSS + JavaScript），不需要任何後端伺服器、不需要建置流程（build step）。
- 所有作品資料只存在你瀏覽器的 `localStorage` 裡，Claude／Anthropic 或任何第三方都不會看到你的內容。
- AI 生成功能由你自己的 API 金鑰驅動，直接從瀏覽器呼叫你指定的 AI 服務。
- 除了逐節生成，也支援針對單一小節「依修改建議微調」、全書「AI 審核」（連貫性與是否符合設定的評分與建議），以及把已完成內容排版成仿日系／台灣出版風格的電子書預覽並匯出成獨立 HTML 檔。

## 檔案結構

```
index.html   主頁面
style.css    版面與視覺樣式
app.js       應用程式邏輯（狀態管理、渲染、AI 呼叫）
README.md    本說明文件
```

## 部署到 GitHub Pages

1. 在 GitHub 建立一個新的 repository（公開或私人皆可）。
2. 把 `index.html`、`style.css`、`app.js` 三個檔案上傳到 repository 的根目錄（直接拖曳上傳或用 `git push` 都可以）。
3. 進入該 repository 的 **Settings → Pages**。
4. 在「Build and deployment」的 Source 選擇 **Deploy from a branch**，Branch 選擇 `main`（或你的預設分支）、資料夾選擇 `/ (root)`，然後儲存。
5. 等待一兩分鐘，GitHub 會給你一個網址，格式通常是：
   `https://<你的帳號>.github.io/<repository 名稱>/`
6. 打開這個網址，即可開始使用。

之後每次修改檔案並推送到該分支，GitHub Pages 會自動重新部署。

## 設定 AI

進到網站後，先到「AI 設定」分頁：

1. 選擇服務提供者。
2. 填入 API 端點網址與模型名稱。
3. 貼上你自己的 API 金鑰。
4. 按「測試連線」確認可以正常呼叫。

**重要限制（瀏覽器跨網域限制，CORS）：** GitHub Pages 是純靜態網站，沒有伺服器可以幫忙轉發 API 請求，所以是瀏覽器直接對 AI 服務商發送請求。

- **Anthropic（Claude）**：官方已支援瀏覽器直接呼叫（需要加上 `anthropic-dangerous-direct-browser-access` 標頭，本網站已自動處理），穩定可用。
- **Google（Gemini）**：Gemini 的 `generateContent` 端點本身就允許瀏覽器跨網域直接呼叫，不需要特殊標頭，同樣穩定可用；到 https://aistudio.google.com/app/apikey 即可申請金鑰，通常有免費額度可先試用。
- **OpenAI**：官方 API 通常會擋掉瀏覽器直接呼叫，直接從這個網站呼叫大機率會失敗。若要用 OpenAI 的模型，建議透過支援瀏覽器呼叫的中介服務（例如 OpenRouter），或自己架設一個小型的伺服器端 Proxy 來轉發請求。
- **自訂端點**：可填入任何相容 OpenAI Chat Completions 格式、且該服務允許瀏覽器跨網域呼叫的 API 位址。

API 金鑰只會存在你自己瀏覽器的 `localStorage` 裡，直接送往你設定的 API 網址，不會經過任何其他伺服器；但也因為是明碼存在本機，請不要在公用電腦上填入金鑰，也不要把匯出的瀏覽器資料分享給別人。

## 資料備份

因為資料只存在瀏覽器本機，請養成定期備份的習慣：

- 「匯出／備份」分頁可以把單一作品匯出成 `.json` 備份檔（不含金鑰），或匯出成 `.txt` 純文字小說檔。
- 側欄下方「匯入備份」可以把 `.json` 備份檔重新匯入（可用於換瀏覽器、換裝置，或救回不小心清除的資料）。
- 清除瀏覽器快取／記錄前，記得先匯出備份。
